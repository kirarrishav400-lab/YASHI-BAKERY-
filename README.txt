# Yashi Bakery & Doodh Dairy Website

## Files
- `index.html` - main website
- `style.css` - design and responsive layout
- `script.js` - menu, gallery lightbox and form messages
- `assets/` - photos extracted from the provided shop video

## Publish for free
### GitHub Pages
1. Create a GitHub account.
2. Create a new repository.
3. Upload all files and the `assets` folder.
4. Go to Settings → Pages.
5. Choose the `main` branch and save.

The website will then receive a free GitHub Pages address.

## Important
The Order and Feedback forms currently work as a website demo and show a confirmation message.
To receive real customer submissions, connect these forms to a free service such as Google Forms or Formspree.
